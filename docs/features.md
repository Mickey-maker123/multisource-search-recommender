# 功能导览

先运行[Windows 演示](setup.md)并导入维保资料。浏览器入口为 [/demo](http://127.0.0.1:18080/demo)。本页以普通维护员、主管、业务系统开发者、部署管理员四种使用方式介绍现有功能；所有演示对象均为模拟资料。

## 读者与经办人

| 想做什么 | 在页面怎样演示 | 应核对什么 |
|---|---|---|
| 跨来源查资料 | 填普通查询令牌，来源留空，输入“更换滤芯”。依次选关键词、语义、混合搜索 | 卡片显示来源和命中片段。混合检索按名次融合文本与向量通道；界面提示低匹配或服务降级时可继续核对原文 |
| 缩小检索范围 | 来源填 `orders`，类型选 `record`。大库可进一步限定更新起止时间、类别、状态并翻页 | 文档元数据筛选与表内精确字段分开。精确查 `workOrderId=00017` 见[工单教程](cookbook/02-tables.md) |
| 推荐与当前任务有关的资料 | 清除上一次的来源和类型筛选，在「当前任务」填“为设备 A 查找更换滤芯的步骤及对应工单”，点「个性化推荐」 | 读手册里的操作和工单的对应设备。多份返回资料可能存在重叠，片段可回原文 |
| 从一篇资料继续阅读 | 在手册卡上点「相关推荐」；检查返回资料的来源、理由和位置 | 此时推荐围绕正在看的对象。点「显式关联」读取内容方随对象声明的关系；没有声明时关系可以为空 |
| 查依据与版本 | 点击「查看当前源对象与位置」，正文较长时点「继续阅读正文」 | 可读内容含当前版本与位置。TXT/MD 可见字符位置，文本型 PDF 支持页码，DOCX 支持段落。已变更对象会提示重新检索 |
| 记录个人反馈 | 填写与令牌一致的反馈编号，点「收藏」或「不感兴趣」，随后点「撤销本次反馈」 | 服务端核对用户、来源映射及可见性。收藏与撤销有明确的处理结果。[可重放步骤](cookbook/03-recommendations.md) |
| 在授权范围统计 | 清空筛选，用普通令牌点「统计根对象数」，再按来源分组；换主管令牌复做 | 标准小样例导入后，只有主管可见主管清单。普通用户应统计两份手册和两条工单。统计计数的单位是根对象，同文多个分段不重复计数 |
| 查无答案 | 输入库中从未记录的本单位实时业务数据，查看匹配提示、通道及来源 | 搜索能报告无匹配或弱匹配；推荐仍可能返回背景资料。页面展示资料依据，由读者判断与实际业务是否相符 |

## 接入与运维

| 接入方式 | 现有支持及复核入口 |
|---|---|
| 在线目录 | TXT、Markdown、HTML、文本型 PDF、DOCX。管理页选预先批准的目录并导入、查看进度和逐项错误。再次扫描会识别修改、配置变动及授权变动；启用缺失删除后，在完整成功扫描时同步删除。[操作教程](cookbook/01-documents.md) |
| 结构化行 | CSV、规则 XLSX 依赖表头、稳定主键、标题和类型映射。字符串、日期、布尔、十进制字段按类型比较。敏感字段与可进入语义正文的字段分开配置。单行形成一个带来源行键的对象。[操作教程](cookbook/02-tables.md) |
| 帖子与标准内容 | 帖子适配器读取纯文本或 Markdown 和约定元数据。后台也可把自有对象转为规范 JSON，调用在线批量写入；明确父子或业务关系后，可从任一有权查看的目标回查。论坛的 HTML 正文需由接入方转换；文件目录的 HTML 解析走独立路径 |
| 只读数据库 | MySQL 适配器要求授权视图提供 `native_id, version, title, body, category, status, updated_at, acl_group, deleted`。它采用校验服务身份的 TLS 与指定视图的 SELECT 权限，数据更新和删除以对象版本和标志同步。首次接真实库应在实际驱动、证书、GRANTS 和视图上验收。模拟业务行覆盖的是映射与写入 |
| 用户与反馈 | 后台把各来源本地用户显式映射为规范用户，提供群组、画像许可、偏好及订阅。事件带来源、用户、动作、对象和时间，支持幂等与撤销。长期兴趣受许可、行为语义和时间衰减约束。下载和曝光的默认兴趣权重为零；社区有效评论按每人、每帖、每天封顶 |
| 运行状态 | 管理员区展示存储、导入、解析、关键词与向量索引、模型队列。输入管理员令牌，读来源、预览表格、启动导入和检查失败详情。解析任务完成后继续观察索引覆盖，必要时按任务 ID 重试 |
| 文件限制 | 扫描件缺少可提取文本时返回需 OCR 的状态。DOCX 解析正文与段落，规则工作表按配置读取。音视频转写、通用图表识别、跨单位独立索引查询属于后续扩展 |

### 论坛怎样接入

1. **在后台映射帖子。** 用稳定的域、来源和帖子 ID 标识对象，显式传标题、正文、版本、栏目权限。帖子下线或栏目撤权时提交相应更新；附件可借助父对象关系继承读取限制。
2. **在论坛页面展示。** 主题列表调用搜索；帖子页调用 `kind=related`；首页使用 `kind=personal`。把查询身份映射到本机配置中的用户与组。管理员写入令牌仅供后台使用。
3. **接入用户行为。** 取得画像许可后，按事件发生时间上报有效阅读、收藏或撤销；前端把推荐理由和「查看来源」入口一起展示。离线适配器另支持将来源本地用户编号映射为规范 ID。
4. 在隔离的演示部署中运行随包[论坛 API 示例](../examples/forum/demo.py)，观察批量写入、统计、显式关系与相关推荐，然后检查撤权和删除后的结果。该示例用合成帖子验证后端调用，真实论坛需提供自己的前端及同步适配器。

```powershell
python examples/forum/demo.py
```

## HTTP 入口速查

表中的业务前缀是 `/api/engine/v1`，管理前缀是 `/api/engine/admin/v1`。写入与管理使用管理身份，普通终端使用查询身份请求资料与本人反馈。完整字段、响应及请求约束见 [OpenAPI](../contracts/v1.6/openapi.json)。

| 请求 | 输入与用途 | 最短检查 |
|---|---|---|
| GET 业务 `/health` | 引擎存活与能力状态 | 浏览器访问 [health](http://127.0.0.1:18080/api/engine/v1/health) |
| POST 业务 `/items:batch` | 可信来源按稳定对象键和单调版本批量写入、更新或删除 | 运行论坛示例，再查对象是否可见 |
| POST 业务 `/users:batch` | 写入用户、群组、来源身份映射、订阅和许可 | 执行演示导入，切换 operator 与 supervisor 核对可见范围 |
| POST 业务 `/events:batch` | 本人行为或管理端可信事件批次 | 收藏一次后撤销，观察两个请求的处理状态 |
| POST 业务 `/search` | 关键词、向量、混合查询；精确条件、过滤和分页 | 用工单教程分别查 `00017` 和 `17` |
| POST 业务 `/recommendations` | `personal` 可接当前任务；`related` 指定参考对象 | 在浏览器分别点击两种入口，观察对象与理由 |
| POST 业务 `/source` | 提交对象引用，按当前权限读元数据 | 对任一卡片点击查看来源，核对版本 |
| POST 业务 `/source-content` | 指定对象、版本、命中位置读取原文；长文按内容标记续页 | 对照卡片定位信息和原文。版本变化时重新定位 |
| POST 业务 `/analyze` | `count`、`group_by`、`relations` 查询可访问根对象 | 点统计、分组、显式关联，切换身份对照 |
| GET 管理 `/status` | 导入、存储、解析、搜索索引及模型运行状态 | 点击「刷新运行状态」 |
| GET 管理 `/import-sources` | 列出批准的来源 | 点击「读取已配置目录」 |
| POST 管理 `/import-preview` | 提交来源与表格相对文件名检查映射 | 预览 `orders/work-orders.csv`，来源与相对文件名分别填写 |
| POST 管理 `/imports` | 对指定来源创建在线导入任务 | 点击「开始导入」，取得 `runId` |
| GET 管理 `/imports/{runId}` | 读取状态与逐项结果，记录可分页 | 点击「刷新导入进度」，检查 `state` 与 `errors` |
| POST 管理 `/imports/{runId}/retry` | 对可重试失败任务创建关联的新任务 | 更正失败输入后重试，按新的任务 ID 跟踪 |

离线工具 `local.federated.engine.IngestCli` 另支持帖子、文件清单、模拟业务行、只读视图、用户和行为导入，以及对象状态、历史批次查询。该工具与在线进程互斥访问嵌入式 H2；需要持续接入的生产者优先用在线目录或规范 HTTP 写入。
