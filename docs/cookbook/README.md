# Cookbook · 多源搜索推荐实操手册

用同一组设备维保资料走通三条接入路径。首次使用请先按[安装与启动](../setup.md)准备演示环境。以下示例在仓库或 Windows 演示包的根目录用 PowerShell 执行，可以按需选择一篇。

| 教程 | 从什么开始 | 完成后怎样核对 |
| --- | --- | --- |
| [文档目录与版本更新](01-documents.md) | 两份 Markdown 手册和已批准的导入目录 | 检索“更换滤芯”并打开对应段落。修改工作副本后再次导入，核对新增内容与版本。 |
| [工单表与精确查询](02-tables.md) | CSV、稳定主键和列类型映射 | 用字符串 `00017` 查到一条记录，改用 `17` 返回零条；打开来源可核对行键。 |
| [任务推荐、访问权限与反馈](03-recommendations.md) | 一项维保任务、维护员与主管两个身份 | 从一次推荐打开手册与工单；切换身份验证主管清单的可见范围，记录并撤销收藏。 |

接入论坛后端时，可继续阅读[帖子、用户、权限与行为同步示例](../features.md#论坛怎样接入)。请求与响应字段见 [HTTP API 合约](../../contracts/v1.6/openapi.json)。
