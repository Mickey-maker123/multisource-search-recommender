# 按任务推荐资料，切换身份并撤销反馈

**结果**　同一个任务同时找到手册和工单，点击结果能回到匹配原文。普通维护人员只读班组资料，主管可以额外读取签收清单。先按照[安装与启动](../setup.md)启动三项服务。

```powershell
.\scripts\import-demo.ps1
$cred = Get-Content -Raw -Encoding UTF8 .local\credentials.json | ConvertFrom-Json
$cred.queryToken | Set-Clipboard
```

1. 在 [/demo](http://127.0.0.1:18080/demo) 的「查询令牌」粘贴普通维护人员令牌，来源留空；「当前任务」填 **为设备 A 查找更换滤芯的步骤及对应工单**，点「个性化推荐」。在卡片中找到设备 A 手册和更换工单，分别打开「查看当前源对象与位置」。手册写明登记备件批号，工单对应 `00017`。
2. 从一张结果卡点「相关推荐」，查看围绕该资料返回的其他结果与入选理由。要恢复任务推荐，在原任务输入框下再点「个性化推荐」。
3. 在「反馈用户编号」填 `operator`。在一张卡片上点「收藏」，观察“已记录”，随即在同一张卡上点「撤销本次反馈」，观察“已撤销”。再点「个性化推荐」。撤销关联原事件；刷新页面会丢失这个临时撤销按钮。一次收藏不保证名次立刻变化。
4. 检查权限时，在「来源」填 `supervisors`，关键词填 **复核签收**，点「检索」。普通身份应得零条。点「清除身份与结果」，回到 PowerShell 执行下列命令，换成主管查询令牌，再以相同关键词和来源检索。
   
   ```powershell
   $cred.managerToken | Set-Clipboard
   ```

   主管可看到并打开《主管复核签收清单》。这一步只替换身份，问题、资料和检索设置都相同。演示结束点「清除身份与结果」，清空系统剪贴板。

```powershell
Set-Clipboard -Value ''
```

若响应含 `ACTOR_MISMATCH`，检查反馈用户编号是否与令牌一致。出现 `SOURCE_IDENTITY_UNMAPPED` 时检查管理员已为用户建立该来源的身份映射。默认 `open`、`download` 只记录动作，任务文字带有效期，长期兴趣使用独立的偏好与行为许可。业务前端可以让用户看到理由、核对原文、表达不感兴趣或撤销反馈。
